# ChronoSelf (su Prime72 / Vercel)

Il dominio e il progetto Vercel restano quelli di Prime72.
La homepage è ora ChronoSelf: simulatore di tre futuri (inerzia, miglioramento, deriva).

- `index.html` — interfaccia
- `chronoself.js` — questionario + motore

I dati restano nel browser (localStorage). Nessun account richiesto.

Dopo il push su `main`, Vercel pubblica in automatico.
